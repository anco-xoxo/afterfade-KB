# Afterfade CS Onboarding — Checklist

Work through this checklist during your first two weeks. Tick off each item as you complete it. Your supervisor will verify completion at the end of each day.

## Week 1: Learn

### Day 1 — Setup & Overview

**Goal:** Understand who Afterfade is, get your tools working, see the customer-facing site.

- [ ] Read `Andrea/onboarding/ONBOARDING.md` sections 1–2 (Welcome & Products)
- [ ] Get accounts set up: Shopify, Sendcloud, Trello, email (hello@afterfade.be), WhatsApp
- [ ] Read `kb/company/overview.md` and `kb/company/languages.md`
- [ ] Browse afterfade.be — homepage, shop, FAQ, about page
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/homepage.md`
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/shop-md`
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/faq-s.md`
- [ ] Read `kb/product_families/product_names_by_language.md` — know the product names in all 7 languages

**End of day check-in:** Can you explain what Afterfade sells and list the main products with prices?

### Day 5 — Simulation & Go-Live

**Goal:** Handle realistic customer scenarios with supervision. Understand daily workflow.

- [ ] Read `Andrea/onboarding/ONBOARDING.md` sections 8–10 (Communication, Escalation, Daily Workflow)
- [ ] Read `kb/definitions.json` — know what Trespa and door wreath mean
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/shipping-policy.md`
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/refundPage.md`
- [ ] Read `Andrea/Questions and summaries /WebsiteMapping/terms-and-conditions.md`
- [ ] **Simulation:** Handle these scenarios with your supervisor watching:
  1. Customer asks "How many bottles do I need for my house?" (12 windows, 2 doors)
  2. Customer says "My order hasn't arrived, it's been 2 weeks"
  3. Customer wants to return an unopened kit
  4. Customer asks "Is this product safe? Can I touch it?"
  5. Customer shares a before/after photo
- [ ] Review the dashboard (`dashboard/`) — understand opening/closing checklists
- [ ] Review `data/contacts.json` and `data/payment_methods.json` for reference data

**End of day check-in:** Debrief with supervisor. Clarify any gaps. Confirm readiness for supervised live handling.

## Week 2: Supervised Live

### Day 6–7 — Supervised email handling

- [ ] Process real customer emails with supervisor review before sending
- [ ] Create real shipping labels in Sendcloud (supervised first, then independent)
- [ ] Log every task in Trello
- [ ] Flag any questions not covered in the KB — log in `data/questions.json`
- [ ] Daily check-in with supervisor

### Day 8–9 — Increasing independence

- [ ] Handle emails independently (supervisor spot-checks)
- [ ] Process a return request end to end (notification → label → tracking → refund)
- [ ] Handle a shipment investigation
- [ ] Create a discount code for a customer who shared photos
- [ ] Daily check-in with supervisor

### Day 10 — Full independence

- [ ] Handle a full day of customer messages independently
- [ ] Complete opening and closing checklists on dashboard
- [ ] End-of-week debrief with supervisor
- [ ] Note any KB gaps or unclear procedures for future improvement
