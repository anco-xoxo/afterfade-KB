# SOP — User-Generated Content (UGC) & Discount Codes

## When to use
Use when a customer shares photos, before/after results or a testimonial of their Afterfade application, or is willing to do so. Also use when creating any discount code in Shopify (free replacement, goodwill, or UGC incentive).

## The offer
- Customers who share user-generated content of their Afterfade results (e.g. before/after photos of their treated surface, a testimonial or review) receive a **10% discount on their next order**.

## Steps — UGC workflow
1. **Log the task.** Create a card on the task board (see `SOP-task-management.md`) so the UGC and the discount are tracked.
2. **Confirm consent.** Confirm the customer agrees to Afterfade using the content (e.g. on the website, social media or marketing). Do not use content without consent.
3. **Receive the content.** Ask for the photos or testimonial (by email, WhatsApp or web chat) and attach it to the task card.
4. **Share the offer.** Confirm the 10% discount on the next order and how it will be applied.
5. **Apply the discount.** Follow the Shopify discount code steps below to create the code.
6. **Close out.** Note the discount given and the content received on the task card.

## Creating a discount code in Shopify
1. **Go to Discounts.** In the Shopify admin sidebar, navigate to **Discounts** and click **Create discount**. Choose the type (e.g. Amount off products, Amount off order, Free shipping).
2. **Set the discount code.** Under **Method**, select **Discount code**. Type a custom code (e.g. `VERVANGINGGUNTER`) or click **Generate** for a random one.
3. **Configure the value.** Set the type (percentage or fixed amount) and value. For a free replacement, set **100% off** or the fixed product amount (e.g. EUR 79.95).
4. **Set usage limits — the key step.** Under **Maximum discount uses**:
   - **Limit number of times this discount can be used in total** — caps total uses across all customers.
   - **Limit to one use per customer** — check this box so each customer can redeem it only once, even if the code is shared.
   - For a truly single-use code for one specific person, also set the total usage limit to **1**.
5. **Set an expiry date (recommended).** Under **Active dates**, set an end date so the code does not remain valid indefinitely.
6. **Save.** Click **Save discount**.

## Notes
- Only offer the discount in exchange for content the customer actually shares; do not give it out loosely.
- Escalate to a human if a customer asks for more than the 10% discount or wants it applied retroactively.
- Log the discount on the task card with the customer, code and value.
