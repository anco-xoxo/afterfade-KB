# SOP — Task Management

## Purpose
All Afterfade CS-ops tasks must be tracked in Vocero or Trello. Nothing should be carried out only in private notes, email or chat — if it is a task, it has a card.

## Task board
- **Board:** Afterfade CS Ops — https://trello.com/b/tJxpuJim/afterfade-cs-ops

## Rules
1. **Log every task.** When a task is received (from a customer, the team, or an escalation), create a card on the Trello board (or log it in Vocero) before starting work.
2. **Use Vocero or Trello, not both.** Pick the tool the task came in on and keep it there; do not duplicate cards across both.
3. **One task, one card.** Each card covers a single, clear deliverable.
4. **Move cards through their stages.** Keep statuses up to date (e.g. To Do → In Progress → Done) so the board reflects reality at all times.
5. **Link related material.** Add the customer, order or chat reference to the card so the context is never lost.
6. **Close out.** When a task is finished, update the card to Done and note the outcome before moving on.

## Exception
Short, immediate actions that are resolved in the moment (e.g. a quick reply that needs no follow-up) do not need a card — but anything that requires follow-up work, waiting on someone, or a decision must be logged.
