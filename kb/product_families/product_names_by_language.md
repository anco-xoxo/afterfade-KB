## The naming rule
Always use the name for the customer's own language from the lists above — this is the exact name printed on their version of the site, not a fresh translation. Never translate a product name on the fly, and never invent a name for a language that is not listed here: if a future product or locale has no translated title recorded, fall back to the English name rather than guessing. Prices, currency (EUR) and SKUs stay the same in every language regardless of which name is used — see `company/languages.md`.
